# 数据与实验版本地图

## 最新规范与历史实验分离

现行规范为 S3-personal-opinion-v1 与 T-nonauthoritative-v1，见当前英文 Prompt 和中文框架表。新版尚未生成数据或运行评测。下表的全部样本、脚本和结果是历史实验，不代表新方法。旧的独立中文设计规范已从 materials 删除，历史来源仍可在 Git 历史与证据归档中追溯。

| 目录 | 解释 |

## 已有结果锚点

首次全量 clean 严格错误为 79/812，其中 Noul 4/314、Choice 10/337、Score 65/161。12 类对抗候选合计严格错误 1,810/9,744；它描述的是历史全量版本。

S3-v5 原标签偏离为 548/812：Noul 149/314、Choice 259/337、Score 140/161。首次 clean 正确的 733 题中，474 题在 S3-v5 偏离，即 474/733。它不自动等于对修改后规则的错误率。

S3-v5 Noul：原 true 159 题中 146 偏离；原 false 152 题中 0 偏离；原 interval 3 题中 3 偏离。统一采用 A AND B 时，原 A=false 不会因逻辑收窄自然变成 true，必须分组解释。
