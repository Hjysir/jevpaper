# 研究想法与动机

## 来源说明

这份文件整理项目已有想法，不把新的推断当作作者已验证结论。主要依据：两版 BadJev 演示文稿、BadJev_案例汇总.md、四类扰动设计文件，以及作者 2026-09-23 关于研究范围与动机的讨论。该讨论中的相关原始文字如下；未复制无关对话、私人附件路径或工具日志。

## 作者此前采用的研究表述

> 随着人工智能由内容生成走向自动化决策，模型的结构化判断及概率输出正直接参与任务调度、权限审核与工具调用，错误判断可能沿执行链条转化为系统风险。面向校准决策的新型训练方法为提升自动化能力提供了技术路径，但格式合法与概率校准并不意味着对抗环境下的决策安全，既有大语言模型安全方法在此类场景中的适用性仍需研究。项目面向智能决策模型的高质量通用评测、对抗鲁棒性与可信执行需求，从鲁棒评测基准构建、决策概率联合攻击和模型执行协同防御三个层面，研究基于可信事实、独立标注与语义等价扰动的安全评测方法，面向合法输出空间的定向决策操控、执行阈值诱导与概率信息泄露机制，以及融合候选动作权限约束、对抗风险校准、概率最小化暴露与执行前验证的分层防御方法，揭示此类模型与传统大语言模型的风险共性及特有机制，为智能决策系统的安全评估与可信部署提供方法支撑。

作者明确希望研究范围覆盖 Jev 及相应的校准决策训练方法，以 Jev 为具体切入点；研究动机并不限于某个产品。这里的“校准决策强化学习 / RLCD”沿用项目材料用语；正式定义应结合归档的官方原始材料核对。

## 核心想法

1. 结构化输出合法不等于决策安全。模型即使始终在候选空间内返回选项，也可能在受到干扰后选择错误对象、错误路由或错误权限判断。
2. 输出风险不只来自最终标签。完整 probabilities、top-label probability、独立 confidence 及 Noul 概率是不同信号，需要分别分析其对排序、阈值决策和潜在信息暴露的作用。
3. 风险会沿程序的执行链传播。模型选择、程序执行、权限变更、真实影响是不同层次，必须分别寻找证据。
4. 传统提示注入、身份伪装和证据污染可能迁移到结构化决策场景，但迁移强度、机制及防御有效性需要实验检验，不能从接口差异直接断言独有漏洞。

## 项目内的两个框架

- 高层框架来自 BadJev：攻击目的 × 任务形式 × 被利用的输出/机制。目的包括窃取、欺诈、破坏及有害内容相关决策；任务形式是 Noul、Choice、Score。案例是早期观察和研究线索。
- 当前批量实验框架来自对抗 Prompt：Q（语言）、S（结构/规则）、T（State 补充信息）、P（question 中的行为指令），每类三个子类。它描述输入干预方式，不应与高层目的混为一个分类维度。

## 已完成与待验证

已完成：基准构建、五轮模型基线、带来源的人工/默认标签导出、扰动生成、首次全量评测、多版 S3 重新评测、若干 Noul/Choice/T2/T3 小样本诊断、审核及对抗工作台。

尚不能由这些文件直接宣称完成：全部候选独立语义验收；总体安全金标准；与传统大模型的完整受控对照；系统级秘密恢复的统计验证；真实权限/执行损害的闭环验证；分层防御方案的系统有效性评测。防御部分目前主要是研究设想和早期案例观察。
